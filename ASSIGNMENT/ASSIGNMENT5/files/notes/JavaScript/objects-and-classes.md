# Objects and Classes

Objects group related data and behaviour; classes are a template for creating many similar objects.

## Key ideas
- Object literal: `const note = { title: "Hooks", subject: "React" };`
- Class syntax: `class Note { constructor(title) { this.title = title; } }`
- `extends` creates a subclass; `super()` calls the parent constructor.
- `Object.keys`, `Object.values` and `Object.entries` iterate over properties.
